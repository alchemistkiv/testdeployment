Bu site canlı! 🚀

GitHub'a push ettim, internette yayınlandı. İşte deployment bu.

Henüz tıklamadın.

Burada ne oldu?

  1. git push ile kodu GitHub'a gönderdim.
  2. GitHub Actions otomatik tetiklendi (.github/workflows/deploy.yml).
  3. Dosyalar GitHub Pages CDN'ine kopyalandı.
  4. Site bir URL'de yayına çıktı.

Aynı mantık Vercel, Netlify, Cloudflare'de de geçerli — sadece arayüz değişir.
